# proyecto_sprint_7
# Análisis de Anuncios de Vehículos - Proyecto Sprint 7

Esta es una aplicación web interactiva desarrollada en Python utilizando **Streamlit**. El objetivo principal del proyecto es explorar y analizar un conjunto de datos relacionado con anuncios de venta de vehículos en los Estados Unidos, permitiendo al usuario visualizar distribuciones y relaciones de variables de manera dinámica.

Puedes interactuar con la aplicación desplegada en producción aquí:
🔗 [Aplicación en Render](http://proyecto-sprint-7-a0ua.onrender.com/)

---

## Funcionalidades de la Aplicación

La web app cuenta con las siguientes herramientas interactivas de análisis:

*   **Generación de Histogramas:** Permite visualizar la distribución de los datos de los vehículos (por ejemplo, el kilometraje u otras variables numéricas clave) al activar casillas de verificación (*checkboxes*) o botones específicos.
*   **Gráficos de Dispersión (Scatter Plots):** Facilita la comparación de dos variables continuas (como el precio frente al kilometraje o el año del modelo) para identificar correlaciones visuales directas de forma sencilla.
*   **Interactividad Dinámica:** Los gráficos se construyen en tiempo real utilizando la librería Plotly Express, lo que permite hacer zoom, aislar datos y revisar etiquetas detalladas al pasar el cursor.

---

## Tecnologías Utilizadas

*   **Python 3.x**
*   **Streamlit** (Para el desarrollo de la interfaz web interactiva)
*   **Pandas** (Para la manipulación y limpieza del set de datos)
*   **Plotly Express** (Para la creación de gráficos interactivos y dinámicos)
